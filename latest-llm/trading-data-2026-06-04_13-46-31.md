## Column Glossary

| Column | Meaning | Interpretation |
|--------|---------|----------------|
| **Prob %** | Baseline model probability (0-100). Ensemble: 60% LogisticRegression (trend/RSI/ATR) + 40% RandomForest (MACD/stoch/BB/volume) + pattern boost. | ≥65% = TRADE verdict. Higher = stronger signal. |
| **Setup** | Technical setup quality score (0-100). Rule-based from trend alignment, RSI zone, ATR health. | Does NOT decide trades. 80+ = good technical structure. Use as secondary filter. |
| **R/R** | Reward-to-Risk ratio = (Target - Entry) / (Entry - Stop). | >2.0 = good. >3.0 = excellent. |
| **Adj R/R** | R/R adjusted for slippage (configured bps). | More conservative estimate. Use for position sizing. |
| **MACD** | MACD Histogram = MACD line - Signal line. Positive = bullish momentum. | Green bar = momentum up. Red = down. |
| **Stoch** | Stochastic K% (0-100). Momentum oscillator. | >50 = bullish momentum. <50 = bearish. |
| **BB Pos** | Bollinger Bands position (0-1). 0 = lower band, 1 = upper band. | >0.5 = price in upper half (strength). <0.5 = lower half (weakness). |
| **Vol** | Volume trend = current volume / 20-day avg volume. | >1.0x = above average volume (confirmation). <1.0x = below average. |
| **Slip ₹** | Estimated slippage per share in rupees. | Derived from configured bps × entry price. Deduct from expected profit. |
